# Submittals & Shop Drawings

## Material Submittals

Official decisions via Phase 1 codes:

| Code | Meaning | Execution |
| --- | --- | --- |
| A | Approved | May proceed |
| B | Approved as noted | May proceed with notes |
| C | Resubmit | New revision required |
| D | Rejected | Must not be used |
| E | For information | Info only |

## Shop Drawings

`approved_for_execution` is **true only** for current A/B decisions. Trigger rejects AFE on resubmit/rejected/superseded/draft.
